Procedimento na capela

Protótipo WebXR · Meta Quest 3
Itens na capela: 0 / 0
Controles

No Quest: gatilho ou grip pega/solta (sem controle: feche a mão para pegar e abra para soltar). Analógico esquerdo anda, direito gira 30°. Botão A/X ou o botão azul REINICIAR da mesa reiniciam os itens; B/Y pula o tutorial. Toque o botão verde da capela com o dedo para ligar; segure a alça prateada para mover o vidro.

No PC: clique e arraste um item para movê-lo; solte para ele cair. A roda do mouse gira o item enquanto arrasta. Clique no botão verde para ligar a capela e arraste a alça do vidro. Arraste o fundo para girar a câmera.
